# كلامكم نور (Kalamakum Noor)

كلامهم يحيي القلوب — خزانة صوتية متواضعة لأنوار حديثهم الطاهر، نُقدّمها بين أيديكم لاستماع ما يحيي القلوب ويُنير الصدور عليهم السلام.

## البدء

```bash
flutter pub get
flutter run
```
